## Epic 1 · 找得到、抄得走

**目标**：从打开页面到把一条提示词复制走，全程不超过三步。

**Epic DoD**：4 个 story 全 done；`npm test` 与 `npm run build` 通过；线上 `/prompts/` 可访问且子资源不 404；README 写明启动与部署方法。

---

## Story 1.1 · 骨架 + 数据 + 搜索筛选

**Traceability**：FR-1、NFR-1、NFR-3

**作为**我，**我希望**打开就能看到全部提示词并按关键词/分类/标签筛，**以便**三秒内定位。

**验收**
- **AC-1.1.1** 脚手架能 `npm run dev` 起来，`npm run build` 通过，`index.html` 引用 `/prompts/assets/...`。
- **AC-1.1.2** 内置数据 ≥24 条，覆盖 5 个类别，字段完整（id/title/category/tags/when/body/builtin）。
- **AC-1.1.3** 输入"周报"能命中对应条目，输入不存在的词显示空状态。
- **AC-1.1.4** 选分类"编程"再点标签，结果为两者交集；清空筛选恢复全部。
- **AC-1.1.5** `filterPrompts` / `matchPrompt` / `extractVars` 有单测且全绿。

**规模**：中

## Story 1.2 · 详情与一键复制

**Traceability**：FR-2、FR-3、AC-3、AC-7

**作为**我，**我希望**点开看完整内容、知道变量填什么、点一下复制走，**以便**直接粘到对话框。

**验收**
- **AC-1.2.1** 点卡片出抽屉（桌面右侧 / 移动底部），含标题、类别、标签、什么时候用、正文、变量清单。
- **AC-1.2.2** 正文中 `{{变量}}` 高亮，变量清单与之对应。
- **AC-1.2.3** 复制成功：剪贴板内容与 `body` **全等**；按钮文案变"已复制"1.5s 后复原；出现 toast。
- **AC-1.2.4** 剪贴板被拒时降级 `execCommand`；再失败给出可读提示，不静默。

**规模**：中

## Story 1.3 · 收藏、自建、导入导出

**Traceability**：FR-4、FR-5、FR-6、NFR-6、AC-4、AC-5

**作为**我，**我希望**标星常用项、加自己的提示词、并能导出备份，**以便**库能长且不丢。

**验收**
- **AC-1.3.1** 星标后"我的收藏"出现该条；刷新后仍在（localStorage）。
- **AC-1.3.2** 新建提示词后出现在"我的提示词"，标注"仅存本机"，可删除。
- **AC-1.3.3** 导出得到含 `version/favorites/items` 的 JSON 文件。
- **AC-1.3.4** 导入非法 JSON 提示"文件格式不正确"，原有条数不变；部分字段缺失时丢弃该条并汇总"忽略 N 条"。
- **AC-1.3.5** localStorage 不可用时降级为会话内状态并在顶部提示一次，页面不白屏。

**规模**：中

## Story 1.4 · 视觉打磨、响应式、README

**Traceability**：FR-7、FR-8、NFR-5

**作为**访客，**我希望**这页看着专业、手机上也能用，**以便**我愿意分享给别人。

**验收**
- **AC-1.4.1** 视觉符合 SPEC 第三节（底色/卡片/主色/动效/留白六项）。
- **AC-1.4.2** ≥1024px 双栏；<1024px 单栏 + 横向分类条；375px 无横向滚动。
- **AC-1.4.3** 键盘可 Tab 到搜索框、卡片、复制按钮；按钮有 `aria-label`。
- **AC-1.4.4** 三种空状态（搜索无结果 / 收藏为空 / 自建为空）文案到位。
- **AC-1.4.5** README 写明：启动、构建、部署到 `/prompts/` 的步骤与 Nginx 片段。

**规模**：中
