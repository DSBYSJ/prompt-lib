> 产出工作流：`/bmad-product-brief`（Analyst）
> 项目：提示词库 ｜ 上线地址：`https://dsbysj.cn/prompts/`
> 日期：2026-11-04 ｜ 状态：已定稿，交 `/bmad-prd`

## 一、一句话

把我平时散落在聊天记录、备忘录、微信收藏里的**有效提示词**收进一个能搜、能筛、能一键复制的页面，纯静态、无后端、打开即用。

## 二、问题是什么

这不是"想做个网站"，是我每天真实在踩的三个坑：

| 坑 | 具体表现 | 代价 |
|---|---|---|
| **找不到** | 好用的提示词是在某次对话里调出来的，隔两周只记得"我好像写过一版"，翻聊天记录翻不到 | 重新调一遍，几分钟没了，且调不回原来的效果 |
| **不成体系** | 散在微信收藏、备忘录、Notion 页面三处，没有分类，也没有"这条是干什么用的"说明 | 明知道有，就是用不上 |
| **迁移成本** | 换设备、换账号就丢；复制到别处又变成一个孤立的文本块 | 越用越乱，最后放弃整理 |

**关键判断**：我缺的不是"更多提示词"（网上到处都是），是**我自己验证过有效的那几十条**的存放与检索。

## 三、给谁用

| 角色 | 诉求 |
|---|---|
| **我自己**（主要用户） | 想用某条提示词时，3 秒内找到并复制走 |
| 同学 / 同行 | 打开链接就能用，不需要注册、不需要装东西 |
| 未来的我 | 半年后还能看懂"这条当时是怎么用的、变量要填什么" |

## 四、目标

1. **3 秒找到**：搜索 + 分类 + 标签三重筛选，输入即出结果（本地过滤，无网络往返）。
2. **一键复制**：点一下就进剪贴板，并明确告知"已复制"。
3. **看得懂**：每条提示词有用途说明、适用场景、以及需要替换的变量（`{{主题}}` 这类）。
4. **能自己长**：可以新增自己的提示词、收藏常用的，数据存在本地，刷新不丢。
5. **手机上能用**：通勤路上单手能查、能复制。

## 五、非目标（明确不做，含合规原因）

| 不做 | 原因 |
|---|---|
| **用户注册 / 登录** | 个人非经营性备案，不做账号体系 |
| **用户发布 / 评论 / 分享广场** | 这是硬红线：个人备案站点**不得有用户生成内容（UGC）与社交功能**。本站所有提示词由站长维护，用户新增的只存在**自己浏览器本地**，不上传服务器 |
| 后端与数据库 | 没有账号、没有上传，就不需要后端；纯静态还能做到秒开 |
| AI 自动生成提示词 | 本期要解决的是"整理与检索"，不是"生产" |
| 多语言 | 中文自用为主，英文提示词直接混排，不做 i18n 框架 |

## 六、怎么算成功

| # | 判据 | 验证方式 |
|---|---|---|
| 1 | 内置提示词 ≥ 24 条，覆盖 ≥ 5 个类别 | 数数据文件 |
| 2 | 搜索响应无可感知延迟 | 本地过滤；300 条以内应 < 16ms（一帧） |
| 3 | 复制成功率 100% | 点击后校验剪贴板内容与提示词原文一致 |
| 4 | 无后端依赖 | 断网（Service Worker 未启用时）也能打开已加载过的页面；构建产物只有静态文件 |
| 5 | 手机可用 | 375px 宽度下无横向滚动、按钮可点 |
| 6 | 合规 | 页面无任何 UGC 入口、无评论、无分享到广场；有备案号展示 |

## 七、风险与约束

| 风险 | 应对 |
|---|---|
| 个人备案的合规边界 | 见第五节：不做账号、不做 UGC；用户自建的提示词只进 localStorage，并在页面明说"仅存本机" |
| 部署在主域名子目录 `/prompts/` | 必须设置构建 `base: '/prompts/'`，否则静态资源 404；Nginx 用独立 extension conf，不碰主站配置 |
| 剪贴板 API 在非 HTTPS 下不可用 | 本站走 HTTPS；仍保留 `document.execCommand` 兜底 |
| 提示词内容质量 | 内置的每条都要写清"什么时候用"，宁可少而准 |

## 八、交给下一阶段的问题

1. 数据放代码里还是放 JSON？（影响构建与后续更新方式）
2. 搜索要不要做模糊匹配 / 拼音？（中文用户可能打拼音）
3. 收藏与自建提示词，存 localStorage 的哪个键、结构怎么定，才方便以后导出迁移？
