# 产品简报 · 填完变量再复制

> 产出工作流：`/bmad-product-brief`（Analyst）
> 项目：提示词库（prompt-lib）｜Epic 2
> 日期：2026-11-09
> 状态：已定稿，交 `/bmad-prd` 继续

---

## 一、一句话

现在"复制全文"复制出去的还是**模板**，粘到对话框里要自己找 `{{}}` 一个个替换。这个 Epic 要让**复制出去的就是能直接发送的成品**。

## 二、问题是什么（先量，再判断）

对着当前仓库的 24 条内置数据实测：

```
$ node --experimental-strip-types -e "…统计 {{变量}}…"
内置条目: 24
含变量的条目: 24（100%）
变量总数: 63 ｜ 平均每条: 2.6
单条最多: 5（study-plan）
无变量条目: 0
```

**没有一条是"复制完就能直接用"的。** 具体代价：

| 场景 | 现在要做什么 | 代价 |
|---|---|---|
| 桌面端复制一条 3 变量的提示词 | 粘贴 → 肉眼找到 3 处 `{{}}` → 逐个选中替换 | 十几秒，且容易漏掉一处 |
| 手机上（通勤路上） | 同上，但光标定位与选中都更费劲 | 漏改变量是常态，发出去才发现 |
| 同一条反复用（如每周写周报） | 每次都重新填一遍同样的值 | 重复劳动，且每次都可能填得不一致 |

**关键判断**：不缺提示词，缺的是**从"拿到模板"到"能发出去"这一步**。

## 三、给谁用

| 角色 | 诉求 |
|---|---|
| 我自己（主要用户） | 填几个空 → 复制 → 直接粘到对话框发送，不用回头改 |
| 同学 / 同行（打开链接就用的人） | 不知道 `{{}}` 是什么也能用；看得懂哪些空必须填 |
| 未来的我 | 复用同一条时不重复劳动 |

## 四、目标

1. **在详情里就能填**：为这条提示词的每个变量生成一个输入框，边填边看成品预览。
2. **一键复制成品**：填完点复制，得到的是替换好的文本；**没填的变量保持原样**并在复制前提示还有几处空着。
3. **不填也能用**：不想填就点"复制模板"，行为与今天一致（不破坏既有习惯）。
4. **变量识别只有一处真相**：一律从正文正则抽取，不允许另存一份变量清单（避免"清单与正文不同步"）。

## 五、非目标（明确不做）

| 不做 | 原因 |
|---|---|
| 用 AI 自动填变量 | 本期解决的是"替换"这个机械动作，不是"猜你想说什么"；后者要调用模型，与"纯静态无后端"的架构冲突 |
| 把填过的值存起来跨会话复用 | 看似贴心，实则要处理"哪条对应哪组值"的模型，且涉及本机数据增多；先用着看是否真需要 |
| 多套变量预设（同一提示词存 A/B 两组值） | 同上，过度设计 |
| 把变量类型化（数字/日期选择器） | 63 个变量里绝大多数是自由文本，类型化收益低、维护成本高 |
| 同步到云端 | 个人备案不走账号体系，见 Epic 1 的 brief 第五节 |

## 六、怎么算成功

| # | 判据 | 验证方式 |
|---|---|---|
| 1 | 含变量的条目，详情里能看到与变量数一致的输入框 | 对 24 条逐条断言：输入框数 == `extractVars(body).length` |
| 2 | 填完后复制，剪贴板内容**不含** `{{` | 实测一条 5 变量的用例，复制后检查 |
| 3 | 只填一部分时，未填的变量原样保留，且复制前有提示 | 单测 + 手动 |
| 4 | "复制模板" 与今天行为完全一致 | 回归：内容与 `body` 全等 |
| 5 | 变量抽取只在一处实现 | `grep` 变量正则，只应出现在 `lib/` 一处 |
| 6 | 新增逻辑有单测 | 渲染与"缺哪些变量"的判定都可脱离 UI 测 |

## 七、风险与约束

| 风险 | 应对 |
|---|---|
| 变量名里有空格 / 中文标点 | 沿用 Epic 1 的正则 `\{\{\s*([^{}]+?)\s*\}\}`，渲染时按同名替换（同名变量一次填、全文替换） |
| 用户在输入框里输入 `$&` 等正则特殊字符 | 替换必须用函数式 `replace`，不能用字符串替换，否则 `$&` 会被当成捕获组引用 |
| 变量多时表单把抽屉撑得很长 | 表单区独立滚动，预览区固定高度 |
| 手机端键盘弹出遮挡输入 | 抽屉已是底部弹层，需要 `padding-bottom` 让出安全区 |

## 八、交给下一阶段的问题
