## 二、功能需求

### FR-1 浏览与筛选（P0）

- 分类侧栏（全部 / 写作 / 编程 / 学习 / 求职 / 图像 / 我的收藏 / 我的提示词），带数量角标。
- 顶部搜索框：匹配**标题、用途说明、正文、标签、别名**，大小写不敏感，中文子串即可命中。
- 标签行：点击标签追加筛选，可多选（AND 语义）。
- 搜索与分类、标签可叠加；三者任一变化，列表即时更新（无防抖，本地过滤足够快）。

### FR-2 详情（P0）

- 卡片点击 → 右侧抽屉（桌面）/ 底部弹层（移动）。
- 内容：标题、类别、标签、**什么时候用**、正文（等宽字体、保留换行）、变量清单。
- 正文里的 `{{变量}}` 高亮显示，并在下方列出"需要替换的变量"。

### FR-3 一键复制（P0）

- 详情里"复制"按钮 + 卡片上的快捷复制图标。
- 复制成功后按钮文案变"已复制 ✓"，1.5s 后复原；同时右下角出现轻量 toast。
- 失败要有提示（不是静默失败）。

### FR-4 收藏（P0）

- 卡片与详情都有星标；收藏项进"我的收藏"分类。
- 存在 `localStorage`，刷新不丢。

### FR-5 自建提示词（P1）

- 表单：标题、类别、标签、正文。保存后进"我的提示词"。
- **明确标注"仅保存在本机浏览器"**（合规：不上传服务器）。
- 可删除自建项。

### FR-6 导出 / 导入（P1）

- 导出：把收藏 id + 自建提示词打包成 JSON 下载。
- 导入：选择 JSON 文件，校验结构后合并；不合法给出明确提示，不污染现有数据。

### FR-7 空状态（P1）

- 搜索无结果："没有匹配的提示词" + 清空筛选按钮。
- 收藏为空、自建为空：各自的引导文案。

### FR-8 外观与适配（P0）

- 深色为主，玻璃质感卡片 + 渐变点缀；动效克制（入场淡入 + hover 微抬）。
- 响应式断点：≥1024 双栏（侧栏 + 列表）、<1024 单栏 + 顶部横向分类条。
- 375px 宽下无横向滚动。

## 三、非功能需求

| ID | 要求 | 度量 |
|---|---|---|
| NFR-1 | 首屏快 | 构建产物 JS + CSS gzip ≤ 120 KB（不含内置数据单独评估） |
| NFR-2 | 搜索快 | 300 条以内单次过滤 < 16ms |
| NFR-3 | 无后端 | 构建产物只有静态文件，无任何 `fetch` 到自家接口 |
| NFR-4 | 可测 | 搜索/过滤/存储序列化抽成纯函数，有单测 |
| NFR-5 | 可访问 | 按钮有 `aria-label`，键盘可达，对比度达标 |
| NFR-6 | 数据可迁移 | localStorage 带 `version`，导出 JSON 含版本号 |

## 四、验收标准

**AC-1** 给定 24 条内置数据，当输入"周报"，那么标题或正文含"周报"的条目全部出现，且计数正确。

**AC-2** 给定选中分类"编程"且标签"重构"，当列表渲染，那么只出现同时满足两者的条目。

**AC-3** 给定点击某卡片"复制"，那么剪贴板内容与正文完全一致（含换行），按钮文案在 1.5s 内变回。

**AC-4** 给定收藏 3 条后刷新页面，那么"我的收藏"仍显示 3 条。

**AC-5** 给定导入一个字段缺失的 JSON，那么提示"文件格式不正确"，且原有数据条数不变。

**AC-6** 给定 375px 视口，那么页面无横向滚动，分类条可横向滑动。

**AC-7** 给定正文含 `{{主题}}`，那么详情里该片段高亮，且"需要替换的变量"列出"主题"。

## 五、边界与失败处理

| 场景 | 期望 |
|---|---|
| 剪贴板 API 被浏览器拒绝 | 降级 `execCommand('copy')`；仍失败则提示"请手动选中复制" |
| localStorage 被禁用（隐私模式） | 收藏/自建功能降级为"本次会话有效"，页面顶部提示一次 |
| 导入文件过大（>1MB） | 拒绝并提示，避免卡死 |
| 数据 id 冲突（导入的 id 已存在） | 以导入为准并提示"覆盖 N 条" |

## 六、对上游三个开放问题的决策

| 问题 | 决策 | 理由 |
|---|---|---|
| 数据放代码还是 JSON | **`src/data/prompts.ts`** | 构建期静态化，零请求、零失败模式；类型检查能挡住字段写错。代价是改内容要重新构建 —— 单人维护可接受 |
| 搜索做不做拼音 | **不做全拼，保留 `aliases` 字段** | 拼音匹配要引入词库（几十 KB）且中文输入法下用户通常直接打汉字；`aliases` 留了后路 |
| localStorage 结构 | `promptlib.v1.favorites` / `promptlib.v1.custom`，后者为 `{version, items}` | 键名带 `v1`，日后迁移可并存读取；导出 JSON 也带 `version` |
