## Epic 2 · 复制出去就是能直接用的

**目标**：从"复制模板"进化到"填几个空、复制成品"，并且不破坏原来的用法。

**Epic DoD**：3 个 story 全部 done；既有 32 条单测仍绿 + 新增模板单测；`npm run build` 通过；
线上 `/prompts/` 可访问且能完成一次"填 5 个变量 → 复制成品"的真实操作。

## Story 2.1 · 模板语法收敛为一处实现

**Traceability**：FR-1、NFR-1、NFR-2、AC-2、AC-5

**作为**维护者，**我希望** `{{变量}}` 的解析只有一份实现，**以便**不会出现"表单 5 个、预览 3 个"的不一致。

**验收**
- **AC-2.1.1** 新增 `src/lib/template.ts`，导出 `TEMPLATE_RE / extractVars / splitTemplate / renderTemplate / findMissing`。
- **AC-2.1.2** `search.ts` 不再持有自己的正则，改为再导出 `extractVars`；既有 32 条单测**全部仍绿**。
- **AC-2.1.3** 单测覆盖：同名合并、`$&` 与 `$1` 原样输出、空串/纯空格视为未填、`findMissing` 去重保序、无变量条目返回空数组。
- **AC-2.1.4** `grep -rn "{{" src/lib src/components` 的结果里，正则字面量只出现在 `template.ts`。

**规模**：小（新增 1 文件 + 改 1 文件）

## Story 2.2 · 抽屉里的变量表单与成品复制

**Traceability**：FR-2、FR-3、FR-4、FR-6、AC-1、AC-3、AC-4、AC-6、AC-8

**作为**我自己，**我希望**在详情里填完变量、看到成品、一键复制，**以便**不用再手动改 `{{}}`。

**验收**
- **AC-2.2.1** 打开含 5 个变量的 `study-plan`，出现 5 个输入框，计数行显示"共 5 个变量 · 已填 0 个"。
- **AC-2.2.2** 输入即时反映到预览：已填位置显示填值（高亮），未填位置显示 `{{变量}}`（虚线样式）。
- **AC-2.2.3** 点「复制成品」：全部填完 → 剪贴板无 `{{`；部分填写 → 未填处保留原样并提示"还有 N 处没填"。
- **AC-2.2.4** 点「复制模板」：剪贴板与 `body` 全等（回归）。
- **AC-2.2.5** 关闭抽屉再打开另一条，表单为空（`key={prompt.id}` 生效）。
- **AC-2.2.6** 无变量的条目（自建纯文本）不显示表单区。

**规模**：中

## Story 2.3 · 样式、移动端与文档

**Traceability**：FR-5、FR-7、NFR-5、AC-7

**作为**手机用户，**我希望**表单能滚、预览不被挤没、有清空按钮，**以便**通勤路上也能用。

**验收**
- **AC-2.3.1** 变量 >8 时表单区独立滚动（`max-height:40vh`），预览区仍可见。
- **AC-2.3.2** 375px 视口下无横向滚动，输入框可点，底部按钮不被安全区遮挡。
- **AC-2.3.3** 「清空」按钮把本条填值复位，预览回到模板状态。
- **AC-2.3.4** 卡片上的复制按钮 toast 文案改为"已复制模板 · 打开详情可填变量"。
- **AC-2.3.5** README 功能列表补上"填变量再复制"，并在"取舍"里说明"填值不持久化"的原因。

**规模**：小
